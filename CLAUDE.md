# Project-Manager — Claude Code Instructions

## Ultra Dev Forge v3 — Active Skill

Ce projet utilise le skill **Ultra Dev Forge v3** — un framework de développement full-stack professionnel.

**Lire et appliquer intégralement** le fichier `.ai/ultra-dev-forge/SKILL.md` et ses références dans `.ai/ultra-dev-forge/references/`.

### Activation automatique

Ce skill s'active dès que l'utilisateur demande :

- Développer une feature, un module, une page
- Créer ou modifier du code (frontend, backend, API, DB)
- Résoudre un bug complexe
- Refactorer ou améliorer le codebase
- Tout travail de développement sur ce projet

### Environnement détecté : Claude Code (CLI)

- Utiliser le filesystem directement (Read, Write, Edit, Bash)
- Exécuter les commandes de validation (`lint`, `typecheck`, `test`)
- Git commits après chaque sprint
- Maintenir un fichier `CONTEXT.md` pour les sessions longues
